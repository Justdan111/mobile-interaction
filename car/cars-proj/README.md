# Cars

## Demo

<!-- Drop an .mp4 here — drag it into GitHub's editor and paste the link. -->

A car showroom that opens on an SVG loader: a circle holds its centre and only
grows while a line sweeps around it, everything linear in progress so every
percent advances the counter and the geometry by exactly the same amount — no
easing to make 90% feel slower than 10%.

Then the car drives in from off the left edge and settles with a small
decelerating overshoot, as if braking to a stop. Onboarding into a collection
and a detail page from there.

Expo 57, expo-router, Reanimated, NativeWind, react-native-svg, expo-image.

## Run

```bash
npm install
npx expo start
```
