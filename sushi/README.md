# Sushi

## Demo

<!-- Drop an .mp4 here — drag it into GitHub's editor and paste the link. -->

A three-screen ordering flow in washi paper, sumi-e ink and vermilion. The paper
is a cream fill under a tiled speckle — tiled, not stretched, because scaling a
noise field up to screen width turns the grain into blotches. Titles set
vertically in kana, an ink sweep behind each dish, and every tappable surface in
the app dips under the finger by the same amount, so the whole thing responds
with one weight.

Onboarding into the menu into a dish detail with a quantity stepper. The dish
cut-outs and ink bitmaps are generated by `tools/make-art.py`.

Expo 57, expo-router, Reanimated, NativeWind, react-native-svg.

## Run

```bash
npm install
npx expo start
```
