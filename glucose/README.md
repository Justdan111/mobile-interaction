# Glucose

## Demo

<!-- Drop an .mp4 here — drag it into GitHub's editor and paste the link. -->

A glucose tracker whose day trace is a filled violet ridge that dissolves into
the black as it falls. The stroke sits only a shade brighter than the crest of
the fill, so the shape reads as a mass of light rather than a plotted line.
Touch anywhere on it to scrub — a crosshair locks to the nearest sample and
calls out the reading at that moment.

Three tabs: today, a graph with a prediction mode and a 7/14-day view, and an
events log. Every figure on every screen — time in range, averages, the grade
badge — derives from one readings series, so nothing can disagree with anything
else.

Expo 57, expo-router, Reanimated, NativeWind, react-native-svg.

## Run

```bash
npm install
npx expo start
```
