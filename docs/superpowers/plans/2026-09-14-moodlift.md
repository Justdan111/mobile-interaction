# Moodlift Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Moodlift — a mood-first fitness app where the selected mood drives colour, copy, mascot and workout ordering across five tabs.

**Architecture:** Expo Router file-based routing with headless tabs from `expo-router/ui`. A `MoodProvider` context holds the one piece of global state (selected mood); every screen reads from it. All numeric figures across the app derive from one solved activity series in `lib/activity.ts` rather than being typed per screen. Presentational components take every colour as a prop.

**Tech Stack:** Expo SDK 57.0.22, expo-router 57, React Native 0.86.2, React 19.2.3, NativeWind 4.2.6, react-native-svg 15.15.4, Fraunces + Inter via expo-google-fonts, qrcode-generator 2.0.4, jest-expo 57.

**Spec:** `docs/superpowers/specs/2026-09-13-moodlift-design.md`

## Global Constraints

- Project root is `moodlift/`. Branch is `moodlift`, cut from `origin/main`.
- Metro is pinned to port **8095** in every npm script. Never start on the default port — Expo Go caches project entries by port and will serve another app's assets.
- Run tests as `npx jest -w 3`. The default worker count oversubscribes this machine's 8 cores and fails otherwise.
- **No component hard-codes a foreground colour.** Text, icon and stroke colours are props with no default that assumes a surface. This defect has recurred repeatedly in this repo.
- Commits and PRs carry the repo owner's authorship only. Do not add `Co-Authored-By: Claude`, "Generated with Claude Code", or a `Claude-Session:` trailer.
- One PR per task group, opened against `main`, never pushed to `main` directly.
- Mood blurbs for Calm, Balanced and Energized are transcribed verbatim from the comps and must not be reworded:
  - Calm — `You feel relaxed and grounded. Looking for mindful movement.`
  - Balanced — `You focused. A good moment for controlled, full-body training.`
  - Energized — `You feel active. Time for dynamic workouts and higher intensity.`
- Reference comps live in `moodlift/.design/comps/`. Each UI task names the comp it must match.

```ts
const RANK: Record<Intensity, number> = { low: 1, medium: 3.5, high: 6 };

export function matchWorkouts(workouts: readonly Workout[], mood: MoodId | null): Workout[] {
  const byTime = (a: Workout, b: Workout) => Date.parse(a.startsAt) - Date.parse(b.startsAt);
  if (!mood) return [...workouts].sort(byTime);
  const target = getMood(mood).rank;
  return [...workouts].sort((a, b) => {
    const tagged = Number(b.moods.includes(mood)) - Number(a.moods.includes(mood));
    if (tagged !== 0) return tagged;
    const fit = Math.abs(RANK[a.intensity] - target) - Math.abs(RANK[b.intensity] - target);
    if (fit !== 0) return fit;
    return byTime(a, b);
  });
}
```

```ts
import qr from 'qrcode-generator';
export function qrMatrix(payload: string): boolean[][] {
  const q = qr(0, 'M');
  q.addData(payload);
  q.make();
  const n = q.getModuleCount();
  return Array.from({ length: n }, (_, r) =>
    Array.from({ length: n }, (_, c) => q.isDark(r, c))
  );
}
```
