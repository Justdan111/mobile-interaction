# Trackit

## Demo

<!-- Drop an .mp4 here — drag it into GitHub's editor and paste the link. -->

A parcel tracker that arrives in choreography rather than all at once. On the
live tracking screen the chart fades up under the header, the lane draws itself,
the origin pin lands, the waypoint drops in, and the ferry finally sails in from
up-lane — while the ETA banner and the sheet are already climbing over the
bottom of the chart, so it reads as one movement instead of a queue.

Tab screens stay mounted, so every entrance is keyed to focus rather than mount:
leaving a tab parks each piece back at its start position and the whole thing
replays on the next visit. Shipments still in transit rock their ferry gently
until they land. Reduced motion is respected throughout.

Expo 57, expo-router, Reanimated, NativeWind, react-native-svg.

## Run

```bash
npm install
npx expo start
```
